# Tone

How the **app** speaks. Distinct from how a Master speaks — that is
`04-masters.md`.

## The rule

The app is the dojo, not the sensei. It is plain, exact and slightly cold.
It never congratulates, never uses an exclamation mark, and never explains
itself twice.

## Concretely

| Do | Don't |
|---|---|
| "Three questions is all a stranger gets." | "You've used all your free questions!" |
| "Mark complete" | "Great job! Mark it done 🎉" |
| "Nothing has been deleted yet." | "Your request has been submitted successfully." |
| "One person reads every message." | "Our team is here to help!" |
| "It doesn't come back." | "This action cannot be undone." |

## Rules that keep catching things

- **Say what is not true yet.** "Message contents aren't in this file yet"
  beats letting the omission be discovered.
- **Errors name the next move**, not the failure. "Email
  privacy@miyamoto.app from this address" beats "An error occurred."
- **Never claim something happened when it might not have.** The one
  deliberate exception is mail delivery (D-025), and it is deliberate.
- **No emoji.** The streak flame is an icon, not an emoji.
- **Numbers over adjectives.** "14h left", "2 of 3", "Day 12".
